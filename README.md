# Zaruma Gestión

Aplicación local para gestión sencilla de presupuestos y facturas.

## Funciones previstas

- Clientes
- Presupuestos autonumerados
- Facturas autonumeradas
- Partidas de mano de obra, materiales y otros conceptos
- Cálculo de base imponible, IVA y total
- Generación de PDF
- Aviso por email del último presupuesto/factura generado
- Logo de empresa en PDF

Activar entorno:

source .venv/bin/activate
