Instrucciones de uso

Guía rápida para usar Zaruma Gestión.

Volver

1. Acceso a la aplicación

La aplicación está protegida por Cloudflare Access. Solo pueden entrar los emails autorizados. Una vez dentro, cualquier usuario autorizado puede usar todas las funciones de la aplicación.

Importante: no hay usuarios ni permisos internos dentro de Zaruma Gestión. Si una persona tiene acceso por Cloudflare, puede crear, modificar y generar documentos.

2. Clientes

Antes de crear presupuestos, proformas o facturas, conviene crear el cliente.

  1. Entrar en Clientes.
  2. Pulsar Nuevo cliente.
  3. Rellenar nombre, NIF/CIF, dirección, teléfono y email si se conocen.
  4. Guardar.

Los clientes se pueden modificar desde el botón Modificar.

3. Catálogo de materiales

El catálogo sirve para guardar materiales habituales con su precio orientativo. Después se pueden seleccionar directamente al crear una partida.

  1. Entrar en Materiales.
  2. Pulsar Nuevo material.
  3. Indicar nombre, categoría, unidad y precio habitual.
  4. Guardar.

Al crear un presupuesto, proforma o factura, se puede seleccionar un material del catálogo. La aplicación rellenará automáticamente el tipo, concepto y precio.

4. Presupuestos

Los presupuestos sirven para preparar una oferta antes de emitir una factura. Se autonumeran automáticamente.

  1. Entrar en Presupuestos.
  2. Pulsar Nuevo presupuesto.
  3. Seleccionar cliente y fecha.
  4. Rellenar título u obra, dirección y notas si hace falta.
  5. Añadir partidas de mano de obra, materiales u otros conceptos.
  6. Guardar presupuesto.
  7. Desde la vista del presupuesto, pulsar Generar PDF.

Un presupuesto se puede modificar mientras se necesite. Si ya tenía PDF generado y se modifica, se deberá pulsar otra vez Generar PDF o Regenerar PDF.

Convertir presupuesto en factura

Desde la vista del presupuesto se puede pulsar Convertir en factura. La aplicación creará una factura nueva copiando cliente, partidas, importes y notas.

Convertir un presupuesto en factura no borra el presupuesto original. El presupuesto quedará marcado como convertido a factura.

5. Facturas proforma

Las facturas proforma son documentos informativos o previos a la factura final. No sustituyen a una factura fiscal definitiva.

  1. Entrar en Proformas.
  2. Pulsar Nueva proforma.
  3. Seleccionar cliente y rellenar los datos.
  4. Añadir partidas.
  5. Guardar.
  6. Generar PDF.

Las proformas tienen su propia numeración automática, independiente de las facturas.

Convertir proforma en factura

Desde una proforma se puede pulsar Convertir en factura. La aplicación creará una factura nueva copiando los datos de la proforma.

La proforma original no se borra. Quedará marcada como convertida a factura.

6. Facturas

Las facturas se autonumeran automáticamente y tienen numeración independiente.

  1. Entrar en Facturas.
  2. Pulsar Nueva factura.
  3. Seleccionar cliente y fecha.
  4. Añadir partidas.
  5. Guardar factura.
  6. Generar PDF.

Modificar facturas

Una factura se puede modificar mientras esté en estado pendiente. Si se modifica una factura que ya tenía PDF, hay que regenerar el PDF.

Marcar como enviada

Cuando una factura ya se ha enviado al cliente, se puede pulsar Marcar como enviada.

Una factura marcada como enviada queda bloqueada para modificación. Esto evita cambiar accidentalmente una factura ya entregada.

7. Facturas rectificativas

Desde una factura se puede crear una factura rectificativa. La aplicación genera una nueva factura con importes negativos para rectificar la factura original.

  1. Entrar en Facturas.
  2. Abrir la factura que se quiere rectificar.
  3. Pulsar Crear factura rectificativa.
  4. Revisar la nueva factura generada.
  5. Generar PDF.
Antes de usar una rectificativa para documentación fiscal real, conviene revisar que los datos, importes y concepto sean correctos.

8. Partidas

En presupuestos, proformas y facturas las partidas se dividen en:

  • Mano de obra: normalmente cantidad = horas y precio = precio/hora.
  • Material: normalmente cantidad = unidades y precio = precio/unidad.
  • Otros / concepto: para conceptos libres, desplazamientos, portes, etc.

El campo de descripción permite varias líneas. Se puede usar para explicar mejor el trabajo realizado o los materiales incluidos.

9. PDFs

Cada documento puede generar su PDF desde el botón Generar PDF. Si el documento ya tenía un PDF, el botón aparecerá como Regenerar PDF.

Los PDFs usan la cabecera de Zaruma configurada en la aplicación.

10. Configuración

En Configuración se pueden revisar los datos generales de empresa y la cabecera que se usa en los PDFs.

Reporte fotográfico en presupuestos

Los presupuestos pueden incluir fotos adjuntas para generar un anexo fotográfico dentro del PDF. Esto es útil para mostrar el estado previo de una obra, zonas afectadas, mediciones, trabajos a realizar o cualquier imagen que ayude a justificar el presupuesto.

  1. Entrar en Presupuestos.
  2. Abrir un presupuesto con el botón Ver.
  3. Bajar hasta la sección Reporte fotográfico.
  4. Pulsar Añadir fotos al presupuesto y seleccionar una o varias imágenes.
  5. Pulsar Subir fotos.
  6. Escribir una descripción si hace falta.
  7. Marcar o desmarcar Incluir en PDF según corresponda.
  8. Pulsar Guardar foto.
  9. Volver arriba y pulsar Regenerar PDF.

Las fotos marcadas como Incluir en PDF aparecerán al final del presupuesto, en una sección llamada ANEXO FOTOGRÁFICO.

Importante: si se añaden, borran o modifican fotos, hay que pulsar Regenerar PDF para que el PDF se actualice.

Gestionar fotos desde modificar presupuesto

En la pantalla de Modificar presupuesto hay un botón llamado Gestionar fotos. Ese botón lleva directamente a la zona de reporte fotográfico del presupuesto.

Las fotos no se suben desde el formulario de modificación principal para evitar confusiones. Se gestionan desde la vista del presupuesto, en la sección Reporte fotográfico.

11. Recomendaciones de uso

  • Crear primero el cliente.
  • Guardar los materiales habituales en el catálogo.
  • Revisar bien las partidas antes de generar el PDF.
  • Si se modifica un documento, regenerar el PDF.
  • No marcar una factura como enviada hasta estar seguro de que está correcta.
  • Usar factura rectificativa si hay que corregir una factura ya entregada.
